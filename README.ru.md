# mods-radar

[English](README.md) · **Русский**

Мод для Claude Code, который показывает, какие плагины с хуками загружены и реально работают в этой сессии и где они мешают друг другу.

Ставишь мод и не понимаешь, работает ли он вообще: может быть включён, но не загружен, загружен, но ни разу не вызван, или тихо падать. А когда несколько модов слушают одни и те же события, один может не дать сработать другому, и никто этого не заметит. mods-radar следит за каждым событием и говорит об этом.

## Установка

В терминальной сессии Claude Code:

```
/plugin install mods-radar --marketplace Darvl-52/mods-radar
```

Ответьте `y`, чтобы добавить маркетплейс, затем выберите область (user — мод будет работать во всех сессиях).

Из командной строки:

```
claude plugin install mods-radar --marketplace Darvl-52/mods-radar
```

В приложении для компьютера, где `/plugin` не работает: нажмите + рядом с полем ввода, затем Plugins, Add marketplace с `Darvl-52/mods-radar`, затем Add plugin.

## Как пользоваться

`/mods` открывает панель со всеми плагинами, у которых есть модуль хуков, сверху внешние в цепочке:

- **зелёный** — замечен в работе в этой сессии (сработали его хуки или он вызывал движок);
- **жёлтый** — загружен, но работы пока не видно;
- **красный** — включён в настройках и имеет модуль хуков, но не загружен, отклонён другим плагином или его хуки падают.

Для каждого: версия, сколько раз срабатывал, последнее событие и время, на какие события подписан. Плагины без модуля хуков (скиллы, MCP, LSP) перечислены одной строкой ниже.

## Конфликты

mods-radar читает трассу движка по каждому событию и сообщает (в первый раз всплывающим уведомлением):

- **перехват** — плагин ответил на событие сам, и плагин ниже, который раньше уже срабатывал на таком же вызове (то же событие, тот же инструмент), в этот раз не запустился;
- **обход** — плагин перепрыгнул уровень другого через `next.to`;
- **подмена** — плагин изменил входные данные события раньше, чем их увидел другой.

Ещё в панели перечислены события, на которые подписано несколько плагинов: там они могут пересечься.

## Ограничения

- Хуки видны только у плагинов ниже по цепочке. У плагинов выше видны только их вызовы движка (`$`), и панель называет, какие это плагины.
- Матчер хука (`{ tool: 'Bash' }`) снаружи не прочитать, поэтому плагин считается перехваченным только на вызове, на котором его уже видели в работе. Если плагин перехватывают с первого же вызова, об этом не сообщится.
- Где срабатывал каждый плагин, хранится в памяти и сбрасывается при перезагрузке mods-radar.
